# Array_operations

Contains basic array operation examples in C.

## Files

- `array.c` - general array example.
- `deleting.c` - array element deletion example.
- `inserting.c` - array insertion example.
- `Traversing_linear_array.c` - array traversal demo.

## Usage

Compile and run each file using a C compiler:

```bash
gcc inserting.c -o inserting.exe
./inserting.exe
```
