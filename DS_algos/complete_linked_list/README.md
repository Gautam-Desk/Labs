# complete_linked_list

This folder contains a full singly linked list implementation in C.

## Features

- insert at beginning
- insert at end
- insert at position
- delete from beginning
- delete from end
- delete at position
- search for a value
- display list and node count

## Usage

Compile and run with:

```bash
gcc complete_linked_list.c -o complete_linked_list.exe
./complete_linked_list.exe
```
