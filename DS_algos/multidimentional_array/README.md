# multidimentional_array

Examples working with multi-dimensional arrays in C.

## Files

- `size_of_array.c` - demonstrates how to calculate sizes for multi-dimensional arrays.
- `spare_matrix.c` - demonstrates sparse matrix handling.

## Usage

Compile with:

```bash
gcc size_of_array.c -o size_of_array.exe
./size_of_array.exe
```
