# DS_algos

This folder contains data structure and algorithm lab examples written in C.

## Subfolders

- `Array_operations/` - array insertion, deletion, and traversal examples.
- `complete_linked_list/` - complete linked list program with menu-driven operations.
- `linked_list/` - single linked list examples, including traversal, search, insertion, and deletion.
- `multidimentional_array/` - examples working with multi-dimensional arrays.

## How to use

1. Open a folder in a C development environment.
2. Compile the `.c` source files with a C compiler like `gcc`.
3. Run the generated executable to test the example.
