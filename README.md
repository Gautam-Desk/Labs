# Labs Repository

This repository contains programming labs, data structure examples, and skill-based demos organized into separate folders.

## Repository Structure

- `DS_algos/`
  - `Array_operations/`
    - `deleting.c`, `inserting.c`, `Traversing_linear_array.c`
    - Includes array operation examples and compiled Windows executables
  - `linked_list/`
    - `single_linked_list/`
      - `searching_linkedlist.c`, `traversing_linklist.c`
      - `insertion_node/` contains linked list insertion examples:
        - `inserting_end.c`
        - `inserting_node_begg.c`
        - `inserting_random_pos.c`
  - `multidimentional_array/`
    - `size_of_array.c`, `spare_matrix.c`
    - Focused on multi-dimensional array handling in C

- `DS_lab/`
  - Simple C demo programs, including `demo.c` and `demo1.c`

- `PSD_lab/`
  - A C demo file: `demo.c`

- `skill_based/`
  - A basic C demo file: `demo.c`

- `workshop_lab/`
  - HTML pages and demo files for web or UI-style lab work
  - Includes `demo_page.html`, `Description_list.html`, `image_hyprlink.html`, `lab_page.html`, `list.html`, `page.html`, `Page_list.html`
  - Contains image files used by the page demos

## Notes

- Most source code is written in C.
- `workshop_lab/` contains HTML-based demos and sample page layouts.
- Some folders include compiled `.exe` files alongside the C source.

## How to Use

- Open source files in a C development environment to review, compile, and run the examples.
- Open HTML files in a browser to view the workshop lab pages.
- You can use this repository as a study reference for basic data structures and programming lab work.
