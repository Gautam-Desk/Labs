What is HTML?

HTML stands for HyperText Markup Language.
It is used to build web pages by marking up text, links, images, and other page elements.

HTML formatting tags help browsers display text in a readable and attractive way.

Explanation

This page shows common HTML text formatting tags and how they affect content. Headings organize information, while tags such as <strong>, <em>, and <u> change the appearance of text.

Example tags like <sup> and <sub> are useful for scientific notation and math, and the <pre> tag keeps spacing exactly as typed.

Use these formatting tags to make HTML content clearer and easier to read. For richer design, combine HTML structure with CSS styling.
