# workshop_lab

Contains HTML and demo files for workshop-style web examples.

## Files

- `demo.c` - C demo file.
- `demo_page.html` - sample demo page.
- `Description_list.html` - HTML description list example.
- `image.jpeg` - image used by HTML demo pages.
- `image_hyprlink.html` - image hyperlink example.
- `lab_page.html` - lab page layout example.
- `list.html` - HTML list example.
- `page.html` - sample HTML page.
- `Page_list.html` - another HTML page list example.
- `man.jpeg` - image asset.

## Usage

Open the HTML files in a browser to view the page demos.
